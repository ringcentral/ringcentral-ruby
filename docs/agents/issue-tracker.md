# Issue tracker: GitHub

Issues and specs live in ringcentral/ringcentral-ruby.
Use the gh CLI for issue operations, specifying this repository.

For multiline issue bodies and comments, use --body-file.

“Publish to the issue tracker” means create a GitHub issue.
“Fetch the relevant ticket” means read the referenced GitHub issue.

Use native GitHub sub-issues and blocking relationships when supported.
Otherwise, record parent and blocker links in issue bodies.

PRs as a request surface: no.
